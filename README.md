# Usurp: The Kingdom (prototype)

A medieval status ladder. Rank is set only by lifetime spend, from Peasant up to King or Queen.

**This is a prototype. All purchases are simulated. No real money moves, and the Founding Houses are fictional lore, not real users.**

## What's in it

- **The Realm**: one leaderboard sorted by lifetime spend, with titles painted onto bands
- **The Rank Ladder**: seat counts and entry floors per title
- **Noble Houses**: the brand sponsorship layer (simulated)
- **Royal Decrees**: 140 character broadcasts, free allowance by rank
- **Court Games**: dice, trivia and a joust bracket, cosmetic badges only
- **The Charter**: why this stays a status product and not a wager

## Files

- `app.js`, `home.js`, `styles.css`, `home.css`, `icon.svg`: the Kingdom art from usurp-kingdom (living map, Court cutaway, crests, banners, rank insignia), unchanged
- `realm.js`, `realm.css`: the Realm game layer (ladder, leaderboard, decrees, houses, court games) built on that art
- `realm.html`: the single page that ties them together (the game prototype; moved off the homepage on 20 Oct 2026, noindex)

## Running it

It's a static site with no build step. Open it in a browser, or deploy the folder to any static host. Progress is saved in the visitor's own browser (localStorage), so every visitor gets their own realm.

## Medieval games and ad slots (21 Oct 2026)
- `/games/` hub plus four games: `games/archery.html`, `games/joust.html`, `games/castle-defense.html`, `games/sword-duel.html`.
  Pages come from `tools/build.py` (GAMES list). Each game is one canvas drawn in code, no image files:
  `games/engine.js` (shared: canvas, input, synthesized sound, overlays, best scores, sharing, the player's
  Crest Studio arms, ad slots, play tracking) and one script per game.
- Thumbnails and share images: `python3 tools/game_shots.py` after the build (plays each game and photographs it).
- Ads are off until configured: set `ADS` at the top of `tools/build.py` (AdSense publisher ID and a display ad
  unit ID), rebuild, deploy. That also writes `ads.txt` and the `google-adsense-account` meta tag. Set `h5: True`
  only after Google approves the account for H5 Games Ads (between-round interstitials via `adBreak`).
  Until then the banner slot shows a Crest Studio house ad, and every third round break (at most every two
  minutes) shows a skippable Crest Studio card. A directly sold banner goes in `ADS['sponsor']`.
- Play tracking: Microsoft Clarity custom events `play_<game>`, `round_<game>`, `finish_<game>`, `share_<game>`,
  `crest_click_<game>`, plus the session tag `game`. Optional GA4 events if `ADS['ga']` is set.
- Local test hook: on localhost each game exposes `window.__ug.st()` (its state) and `window.__ugFreeze`.
- Speed: fonts are self-hosted in `fonts/` (SIL OFL, licences included) and cached for a year; game scripts and
  `games/games.css` are referenced with `?v=<content hash>` by `tools/build.py` and cached for a year (vercel.json).
  After editing any file in `games/`, rerun `python3 tools/build.py` so the pages point at the new version.
- Ads are robust to ad blockers and empty slots: a blocked or unfilled banner shows the house ad, and a between-round
  break that does not start within 2.5 s simply continues the game. Verified with Google's own test ads
  (`test: True` with H5 on shows Google's sample interstitial at the round break).

## Embeddable games (21 Oct 2026)
- `/embed/<id>.html` (archery, joust, castle, duel): just the game, for other sites' iframes. Built by `embed_page()` in
  `tools/build.py`. No analytics, no ad network, no cookies (Microsoft says Clarity must not run on sites aimed at
  under-18s, and embeds will land on class pages). `<base target="_blank">` opens every link in a new tab; links to
  usurp.games carry `?from=embed` or `?from=embed-<game>` so click-throughs show up in Clarity on our own pages.
  noindex, with a canonical to the real game page. The engine's embed mode (`window.USURP_EMBED`) never scrolls the
  host page and shares the game's canonical URL.
- The snippet (`embed_code()`): an iframe 480 x 724 (height falls back to the attribute if a CMS strips the CSS) plus a
  plain text credit link under it, which is the part search engines count as a backlink.
- Where people get it: a "Put this game on your website" box on each game page, and `/games/embed.html` (live preview,
  copy buttons, how-to for WordPress, Blogger, Google Sites, Wix, Squarespace, FAQ). Clarity event `embed_copy_<game>`.
