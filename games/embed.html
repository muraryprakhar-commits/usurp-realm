How to add it

WordPressAdd a Custom HTML block where you want the game and paste the code. On WordPress.com this needs a plan that allows custom code.
BloggerIn the post editor, switch to HTML view, paste the code where you want the game, then switch back.
Google SitesInsert, then Embed, then the Embed code tab. Paste the code, press Next, then Insert. Drag the box taller if the game looks cut off.
WixAdd, then Embed Code, then Embed HTML. Paste the code into the box and resize the element to about 480 by 720.
SquarespaceAdd an Embed block, choose Code Snippet, and paste the code. A Code block works too.
Anywhere elseAny page editor that accepts HTML or an iframe works the same way: paste the code where the game should appear.

Questions

Is it really free?

Yes. Embedding is free for any website, personal, school, club or business. No sign-up, no fee and no key.

Are there ads in the embedded games?

No ad networks. Every few rounds a short card invites players to design their own coat of arms on Crest Studio, our free coat of arms maker, and they continue with one tap.

Do you collect data about my visitors?

The embedded games load no analytics, no advertising and no cookies. Best scores and the sound setting stay in the player’s own browser. See the privacy policy.

Are the games suitable for students?

Yes. There is no blood, no chat, no accounts and nothing to buy inside the games: arrows hit targets, lances shatter, knights yield and walls crumble. They work on school Chromebooks, tablets and phones.

Can I change the size?

Yes. Change the 480 in max-width and width to any size you like; the game scales to fit and keeps its shape. It works from about 300 pixels wide.

Do I need to update the code when you improve a game?

No. The code loads the current version of the game, so fixes and new features reach your page on their own.

Can I put the games on a site that sells things?

Yes. Please keep the credit line under the game. You may not resell the games, put them behind a paywall or present them as your own.
